# Action Design Portfolio Site

A concept website for Action Design LLC, a fabrication business run by my family. I built this as a sample project to practice designing and shipping a small business site. It is **not** the official Action Design website.

**Live demo:** https://henry-tlai.github.io/ActionDesign-WebPortfolio/html/

## About

Action Design is a family-owned fabrication shop. I've worked there on and off, so I wanted to build something that showed off its work the way I'd want a customer to see it: clear, simple, and easy to get in touch.

This site is a portfolio-style showcase of the kinds of projects the shop takes on, plus basic info about the business and how to reach out.
